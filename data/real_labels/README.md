# Real drug-label sample (journal experiment 1: real-world dose errors)

One FDA Structured Product Label per drug, `dosage_and_administration` section (truncated to 8000 chars) and `dosage_forms_and_strengths`, downloaded from the openFDA drug label API on 2026-10-01T07:24:33+0000 by `scripts/journal2/rd_fetch_labels.py` (query and per-drug misses in `manifest.json`; set_id/version/effective_time per row allow re-fetching the exact label from DailyMed).

License: openFDA data (SPL content from DailyMed / NLM) is public domain, released under CC0 (https://open.fda.gov/license/). Not medical advice; labels may have been updated since retrieval.
