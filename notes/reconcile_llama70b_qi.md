## Required QI line format (all reports from now on)

Every QI (and parallel NS/US) line must state:

1. **Subset:** `all` vs `natural` INV-unit (or explicit family list)  
2. **Conditioning:** e.g. `| C0 PASS` (verifier-specific C0 gate)  
3. **Exclusions:** e.g. `non_dose_targets`, `analysis_keep_row`, PI gates  
4. **Source file(s):** instances jsonl + raw score jsonl  

Example (paper):

> **QI** = 76.5% [62.7, 88.2], n=51 — subset **natural INV-unit**, conditioning **\| C0 PASS** (Llama-3.3-70B), exclusions **non-dose main DOSE**, instances `data/t19/instances_t19.jsonl` (`main_dose`), scores `results/raw/v4_ragas_nli.llama.jsonl`.

### V1 raw QI: 77/99 → 36/55 (canonical pipeline)

The drop is **not** a change in non-dose exclusions, natural-vs-all INV subset, or C0 conditioning (still **INV-claim all magnitudes | C0 PASS** on `instances_cpu_early`). It comes from **which score rows are eligible**: the canonical pipeline (`scripts/compute_paper_numbers.py`) keeps only OpenRouter **`v1_medscore`** rows with a logged **`api_model`** matching the registry pin, and joins only instances that pass **`analysis_keep_row`** (PI_ok gates). An older M1 table pass used **`MEDVERIF_SKIP_PROVENANCE_ASSERT=1`**, which allowed **legacy/local rows without `api_model`** into the join—adding **44 extra parsed INV-claim rows** (mostly PASS), inflating QI to **77/99**. After the filter, **36/55** remains on the same subset definition; re-run **`python scripts/compute_paper_numbers.py`** for the current **35/54–36/55** line (cluster bootstrap micro-counts).
