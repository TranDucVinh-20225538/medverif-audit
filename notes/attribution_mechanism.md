- Token groups are character-matched: numbers/units = the dose spans found by `src/unit_norm_fix.find_spans`, drug = generic-name lexicon / suffix rules / `text_utils.DRUG_RE` (drug detection is incomplete for brand names and descriptions such as 'a medication').
- IG baseline = pad embeddings with special tokens kept; shares use |attribution|. Rollout is not defined for the encoder-decoder Flan-T5 and is omitted there.
- Occlusion removes tokens (ungrammatical inputs); it measures reliance, not correctness.
- The overlap regression is observational across perturbation types built from the same bases; the features are near-deterministic functions of condition, so it is a structured contrast, not a causal model.
